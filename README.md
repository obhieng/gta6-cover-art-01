Vice Lights Cover Studio — turn any photo into a multi-panel Vice-style cover with per-panel captions, five sunset/neon grades, halftone + film grain, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Upload 1–3 of your own photos (they never leave your machine) or use the two bundled samples, pick one of 4 layouts and 5 grades, write a caption for every panel, set the title/tagline/credits/issue number, and export the cover as a PNG in three post sizes.
