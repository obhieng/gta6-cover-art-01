Vice Ink Cover Studio — turn any photo into a multi-panel Vice-style cover. The v2 Ink engine turns each panel into comic-book art (posterize + edge ink + halftone dots, level adjustable per panel), on top of 7 layouts, 8 sunset/neon grades, 3 built-in Vice City scene backdrops with blend modes, per-panel captions, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080 — or all three sizes at once. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Upload 1–3 of your own photos (they never leave your machine) or use the two bundled samples, pick one of 7 layouts and 8 grades, set a scene backdrop, write a caption for every panel, switch any panel to Ink for the comic-poster look, set the title/tagline/credits/issue number, and export the cover as a PNG in three post sizes — or all three at once with “Export all 3 sizes”.
