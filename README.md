Vice Type Cover Studio — turn any photo into a magazine-style Vice cover. The v3 title engine draws curved, 3D-extruded, gradient, sticker-outline or neon-glow titles, plus a magazine masthead bar (name + issue + date + price) and cover lines down the right edge. Six one-click Looks apply a complete cover recipe (layout + grade + backdrop + title style + treatment); the new Magazine layout is a full-bleed single photo under the masthead. Underneath it all, the v2 Ink engine still turns any panel into comic-book art (posterize + edge ink + halftone dots, level adjustable per panel), with 8 layouts, 8 sunset/neon grades, 3 built-in Vice City scene backdrops with blend modes, per-panel captions, duotone/threshold/solarize treatments, light-leak + vignette, a before/after compare slider, Surprise me + 20-step undo, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080 — or all three sizes at once. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Upload 1–3 of your own photos (they never leave your machine) or use the two bundled samples, pick a Look or one of 8 layouts and 8 grades, style the title (curved, 3D, gradient, sticker, glow), set the masthead and cover lines, write a caption for every panel, switch any panel to Ink for the comic-poster look, slide Before ⇄ After to check the grade, and export the cover as a PNG in three post sizes — or all three at once with “Export all 3 sizes”.
